# python-warmup
Refreshing Python fundamentals after a break from coding


I first started learning Python in 2019 while working with the data for one of my research papers. At the time, I found Python particularly user-friendly and useful for applying machine learning methods to my research.

However, about a year ago, I changed the methodology of my work due to data limitations and moved away from coding-based approaches. As a result, I have not been working with Python regularly for about a year.

Now that I am returning to coding and machine learning, I felt it would be helpful to revisit the fundamentals and refresh my understanding of the core Python concepts.

This repository is my personal Python warm-up and learning space. It is primarily intended to help me review and rebuild my programming skills, but I hope it can also be useful to others who are in a similar situation—especially researchers who have some previous experience with Python but are returning to coding after a break.

I will gradually add exercises, examples, and notes as I continue learning and refreshing my Python skills.
